# Spider-Verse

An Angular 18 cinematic desktop landing page inspired by the Spider-Verse visual language. Includes a custom spider cursor, subtle hero motion, layered skyline, web geometry, responsive layout, and reduced-motion support.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:4200. Build with `npm run build`.

The hero artwork is CSS-built and uses no external image assets or animation dependencies.
